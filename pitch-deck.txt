SLIDE 2 — OUR SOLUTION: KITA
--------------------------------------------------------------------------------

  KITA is a mobile-first, AI-powered platform that gives small
  Filipino business owners three things — in one app.

  ┌──────────────────────────────────────────────────────────────┐
  │  [1] DIGITAL OPERATIONS                                      │
  │      Smart POS (Tindera mode) · OCR Receipt Scanner          │
  │      Real-time Inventory · Automatic Change Calculation      │
  ├──────────────────────────────────────────────────────────────┤
  │  [2] FINANCIAL INTELLIGENCE                                  │
  │      Groq AI (Llama 3.3 70B) · Daily Taglish Insights       │
  │      7-day trend analysis · Top sellers · Spending patterns  │
  ├──────────────────────────────────────────────────────────────┤
  │  [3] CREDIT IDENTITY — RAFI MFI READY                       │
  │      KYC Verification (Basic / With Business Permit)         │
  │      Loan Readiness Score 0–100 · PDF Export for RAFI        │
  │      Ratings: Mahirap · Sapat · Maganda · Mahusay            │
  │      Matches user to: Mauswagon, Kabuhayan, SAGIP & more     │
  └──────────────────────────────────────────────────────────────┘

  STACK: React Native + Expo · Firebase Auth/Firestore/Storage
         Groq AI (text + vision OCR) · expo-print PDF export

  STATUS: Functional prototype — live on Android
